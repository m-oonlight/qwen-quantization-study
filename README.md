# Qwen quantization study

Private research results and fixed benchmark methods.

One pass of 250 questions per quantization, Q8 through Q2. Pilot/smoke folders are excluded from the study. Each model summary and prompt grade is derived from its canonical results.json.

Large stress/runtime logs are stored as ordered byte chunks with SHA-256 manifests. See setup-methods/BACKUP-SETUP.md for restoration. No model weights, answer keys, hidden tests, account credentials or tokens are included.
